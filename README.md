# Tài liệu nhóm LuxeMotor

Nhánh `lab` dành cho PDF báo cáo. Khang phụ trách cập nhật tài liệu.
Code dự án nằm tại [nhánh main](https://github.com/khangnlpts03231-collab/LuxeCar/tree/main).

- Lab1.pdf: Phân tích yêu cầu, đặc tả chức năng và sơ đồ Use Case.
- Lab2.pdf: Thiết kế dữ liệu, sơ đồ ERD, mô hình triển khai, lưu đồ và Sitemap.
- Lab3.pdf: Xây dựng cơ sở dữ liệu, các lớp Entity và DAO sử dụng JDBC.
- Lab4.pdf: Đăng ký, đăng nhập, phân quyền truy cập bằng Filter và quản lý danh mục.

Các Lab khác được thêm vào đây khi hoàn tất. Không merge nhánh `lab` vào `main`.
